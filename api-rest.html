REST API sederhana dengan PHP native: API Nilai

Membuat endpoint /api/nilai dengan method GET dan POST. Data disimpan di satu file JSON, tanpa framework dan tanpa database.

Tujuan pembelajaran

Setelah materi ini, mahasiswa mampu:

  • menjelaskan konsep REST API, method HTTP, dan status code;
  • membuat routing sederhana berdasarkan path dan method di PHP native;
  • membaca dan menulis data JSON melalui file;
  • menerapkan aturan bisnis (nilai ≥ 60 = Lulus) pada data yang masuk;
  • menguji API dengan curl atau Postman.

1. Konsep dasar

REST API adalah cara dua aplikasi bertukar data lewat HTTP. Klien (browser, aplikasi mobile, Postman) mengirim request, server membalas dengan response berformat JSON.

Setiap request memiliki tiga hal yang perlu diperhatikan: URL/path (sumber daya yang dituju), method (aksi yang diminta), dan body (data yang dikirim, khusus POST).

2. Entitas dan aturan bisnis

Hanya ada satu entitas, yaitu nilai. Klien mengirim nama, mata_kuliah, dan nilai. Server yang menambahkan id dan keterangan, sehingga klien tidak bisa mengubah keterangan sembarangan.

4. Langkah pembuatan

Langkah 1. Buat file data

Buat folder data, lalu isi nilai.json dengan array kosong.

data/nilai.json
[]

Langkah 2. Tulis index.php

Satu file ini menangani semuanya. Baca komentar di kode untuk memahami tiap bagian.

index.php
<?php
header('Content-Type: application/json; charset=utf-8');

const FILE_DATA = __DIR__ . '/data/nilai.json';

// Kirim response JSON lalu hentikan program
function kirim(int $status, array $body): void
{
    http_response_code($status);
    echo json_encode($body, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);
    exit;
}

// Baca isi file JSON menjadi array PHP
function bacaData(): array
{
    if (!file_exists(FILE_DATA)) {
        return [];
    }
    $isi = file_get_contents(FILE_DATA);
    return json_decode($isi, true) ?? [];
}

// Tulis array PHP ke file JSON (LOCK_EX mencegah tabrakan tulis)
function simpanData(array $data): void
{
    file_put_contents(
        FILE_DATA,
        json_encode($data, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE),
        LOCK_EX
    );
}

// Aturan bisnis: 60 ke atas Lulus, di bawah 60 Tidak Lulus
function tentukanKeterangan(float $nilai): string
{
    return $nilai >= 60 ? 'Lulus' : 'Tidak Lulus';
}

// ---------- Routing ----------
$method = $_SERVER['REQUEST_METHOD'];
$path   = rtrim(parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH), '/');

if ($path !== '/api/nilai') {
    kirim(404, ['status' => 'error', 'pesan' => 'Endpoint tidak ditemukan']);
}

// ---------- GET /api/nilai ----------
if ($method === 'GET') {
    $data = bacaData();
    kirim(200, [
        'status' => 'success',
        'total'  => count($data),
        'data'   => $data,
    ]);
}

// ---------- POST /api/nilai ----------
if ($method === 'POST') {
    $input = json_decode(file_get_contents('php://input'), true);

    if (!is_array($input)) {
        kirim(400, ['status' => 'error', 'pesan' => 'Body harus berupa JSON yang valid']);
    }

    $nama = trim($input['nama'] ?? '');
    $mk   = trim($input['mata_kuliah'] ?? '');
    $nilai = $input['nilai'] ?? null;

    $error = [];
    if ($nama === '') $error[] = 'nama wajib diisi';
    if ($mk === '')   $error[] = 'mata_kuliah wajib diisi';
    if (!is_numeric($nilai) || $nilai < 0 || $nilai > 100) {
        $error[] = 'nilai harus angka 0 sampai 100';
    }

    if ($error) {
        kirim(400, ['status' => 'error', 'pesan' => 'Data tidak valid', 'detail' => $error]);
    }

    $data = bacaData();

    // id baru = id terbesar + 1
    $idBaru = $data ? max(array_column($data, 'id')) + 1 : 1;

    $baru = [
        'id'          => $idBaru,
        'nama'        => $nama,
        'mata_kuliah' => $mk,
        'nilai'       => $nilai + 0,
        'keterangan'  => tentukanKeterangan((float) $nilai),
    ];

    $data[] = $baru;
    simpanData($data);

    kirim(201, ['status' => 'success', 'pesan' => 'Data berhasil disimpan', 'data' => $baru]);
}

// ---------- Method lain ----------
header('Allow: GET, POST');
kirim(405, ['status' => 'error', 'pesan' => 'Method tidak diizinkan']);

Langkah 3. Jalankan server

Cara paling mudah adalah server bawaan PHP. File index.php dipakai sebagai router sehingga semua path masuk ke sana.

Terminal (di dalam folder api-nilai)
php -S localhost:8000 index.php

Jika memakai Apache (XAMPP/Laragon) dan ingin URL bersih, tambahkan .htaccess berikut. Pastikan mod_rewrite aktif dan folder ini menjadi document root.

.htaccess
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteRule ^ index.php [QSA,L]

5. Pengujian

Menambah data (POST)

Terminal
curl -X POST http://localhost:8000/api/nilai \
  -H "Content-Type: application/json" \
  -d '{"nama":"Budi","mata_kuliah":"Pemrograman Web","nilai":85}'

Response 201 Created:

Response
{
    "status": "success",
    "pesan": "Data berhasil disimpan",
    "data": {
        "id": 1,
        "nama": "Budi",
        "mata_kuliah": "Pemrograman Web",
        "nilai": 85,
        "keterangan": "Lulus"
    }
}

Menambah data dengan nilai di bawah 60

Terminal
curl -X POST http://localhost:8000/api/nilai \
  -H "Content-Type: application/json" \
  -d '{"nama":"Sari","mata_kuliah":"Pemrograman Web","nilai":45}'

Pada response, keterangan akan bernilai "Tidak Lulus".

Mengambil semua data (GET)

Terminal
curl http://localhost:8000/api/nilai
Response 200 OK
{
    "status": "success",
    "total": 2,
    "data": [
        { "id": 1, "nama": "Budi", "mata_kuliah": "Pemrograman Web", "nilai": 85, "keterangan": "Lulus" },
        { "id": 2, "nama": "Sari", "mata_kuliah": "Pemrograman Web", "nilai": 45, "keterangan": "Tidak Lulus" }
    ]
}

Contoh error

Terminal
curl -X POST http://localhost:8000/api/nilai \
  -H "Content-Type: application/json" \
  -d '{"nama":"","nilai":150}'

Server membalas 400 Bad Request berisi daftar kesalahan di field detail.

Di Postman: pilih method POST, tab Body → raw → tipe JSON, lalu tempel body JSON seperti pada contoh curl.

6. Poin penting untuk dibahas

  • php://input dipakai karena body JSON tidak masuk ke $_POST. Variabel $_POST hanya terisi untuk form biasa.
  • Validasi selalu dilakukan di server, walaupun klien sudah memvalidasi.
  • keterangan dihitung server agar konsisten dan tidak bisa dimanipulasi klien.
  • Penyimpanan file JSON cocok untuk belajar. Untuk data besar atau banyak pengguna, gunakan database seperti MySQL atau PostgreSQL.
  • Pastikan folder data dan file nilai.json dapat ditulis oleh PHP, terutama di server Linux.

Latihan mandiri

  1. Tambahkan field nim dan wajibkan diisi 8 digit angka.
  2. Tambahkan filter di GET, misalnya /api/nilai?keterangan=Lulus.
  3. Tambahkan endpoint GET /api/nilai/1 untuk mengambil satu data berdasarkan id.
  4. Tambahkan grade huruf (A, B, C, D, E) di samping keterangan.
  5. Buat halaman HTML dengan fetch() untuk menampilkan data dalam tabel dan form input.
